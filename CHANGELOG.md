# Changelog

All notable user-visible changes to the Anaconda3 (JupyterLab) TOS application package.

## 2024.10.0-1 — 2026-11-12

### Added
- First release. Anaconda3 (JupyterLab) (`continuumio/anaconda3:2024.10-1`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8115 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/anaconda3docker/`.
